# Every Research Costs One

A simple Factorio mod that reduces all research costs to a bare minimum.

## Features

- **Minimal Research Cost**: Every technology requires only 1 research cycle
- **Single Pack Cost**: Each science pack required by a technology only costs 1 unit per cycle
- **Universal Compatibility**: Works with science packs from any mod:
  - Base game science packs
  - Space Age DLC packs
  - Space Exploration mod packs
  - Krastorio 2 packs
  - Any other mod's science packs

## How It Works

This mod operates at the data-final-fixes stage, processing all technologies and:
1. Setting research cycle count to 1
2. Setting all science pack ingredient requirements to 1 per cycle

## Installation

1. Copy this folder to your Factorio `mods` directory
2. Enable the mod in the mod menu
3. Start a new game or load an existing save

## Compatibility

- Factorio 2.0+
- Works with any other mods that add science packs or technologies
- Does not conflict with other research modification mods
